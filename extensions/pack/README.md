# Copilot Chat Tools Pack

Keep Copilot Chat useful across the three moments where work usually breaks down: the context gets too long, a task stalls while you are away, and you repeat a correction you thought was already settled.

One install gives you the complete flow.

[Japanese README](https://github.com/furukawa658/vscode-chat-tools/blob/main/extensions/pack/README.ja.md)

| Extension | Keep moving when... |
| --- | --- |
| [Tsugi](https://marketplace.visualstudio.com/items?itemName=ShunsukeF.tsugi) | a chat gets fuzzy or slow; hand the task to a fresh chat without reconstructing it manually |
| [Eien](https://marketplace.visualstudio.com/items?itemName=ShunsukeF.eien) | an overnight task stalls; resume quiet processing and keep rollback-ready Git checkpoints |
| [Ne](https://marketplace.visualstudio.com/items?itemName=ShunsukeF.ne-memory) | the same correction keeps returning; review it once and save it as a reusable rule |

Install the full pack, or choose only the extension you need today. Each product has its own setup notes, privacy details, and controls.
