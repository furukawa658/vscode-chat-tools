# Copilot Chat Tools Pack

Copilot Chatの作業が途切れやすい3つの場面を、まとめてつなぐ拡張機能パック。コンテキストが長くなったとき、離席中に処理が止まったとき、同じ修正指示を繰り返したときに使う。

1回のインストールで3つそろう。

| 拡張機能 | こんな場面で使う |
| --- | --- |
| [Tsugi](https://marketplace.visualstudio.com/items?itemName=ShunsukeF.tsugi) | チャットが長くて重い。作業内容を新しいチャットへ引き継ぐ |
| [Eien](https://marketplace.visualstudio.com/items?itemName=ShunsukeF.eien) | 夜間に処理が止まる。チャットを再開し、Gitのチェックポイントを残す |
| [Ne](https://marketplace.visualstudio.com/items?itemName=ShunsukeF.ne-memory) | 同じ修正指示が戻ってくる。一度確認して再利用できるルールにする |

必要な拡張機能だけ個別に入れることもできる。各ページでセットアップ、プライバシー、設定を確認できる。

ソースと不具合報告は [GitHub](https://github.com/furukawa658/vscode-chat-tools) にある。ライセンス: MIT。
